# R10 机械与 PCB 分区

PCB 文件 [eda/NXT-M3-R10.kicad_pcb](eda/NXT-M3-R10.kicad_pcb) 有双层板框、已加载的元件封装、与原生网表一致的装配网络、四个机械孔候选和射频规划。正面机械图见 [mechanical_layout.svg](mechanical_layout.svg)，参数见 [mechanical.json](mechanical.json)，检查结果见 [mechanical_clearances.csv](evidence/mechanical_clearances.csv)。铜层处于预布局，所有装配尺寸 PROVISIONAL。

## 机械尺寸与装配

| 参数 | 尺寸 mm | 依据 |
| --- | ---: | --- |
| 玻璃最大外径、高度 | 29.6、26.4 | 用户实测 |
| 引脚露出长度、直径 | 7.0、0.9 | 用户实测 |
| 相对两引脚中心距 | 16.5 | 用户复测，仅记录该对引脚 |
| 三管中心 | (27,52)、(65,52)、(103,52) | 相对板左上角 |
| 两邻管实测玻璃包络净距 | 8.4 | 38−29.6；仅二维 |
| 玻璃包络最小板边净距 | 12.2 | 2D |
| 拆机座装配与插拔投影占位 | Ø35 | 初始预留，邻位投影间隙 3.0 |
| OLED 中心及背板平面占位 | (65,15)、42×17 | 模块为 0.91 英寸、128×32。实际载板、固定孔与排针 TBD |
| OLED 占位到最近玻璃包络 | 13.7 | 2D |
| 候选共用孔 | (6,6)、(124,6)、(6,74)、(124,74) | M3，孔 Ø3.2，垫柱/头部 Ø8 占位 |

三管的电气逻辑位号为 V1–V3。SJ 1123—76 的电极图和 J13‑1A 条目可用作管脚编号核查参考。管座需要底视和顶视对应、实物定位标记、焊脚中心坐标、脚截面、最大外径、安装高度、插合深度、保持方式和接触材料。拿到实物后以管座插孔到焊脚做无电连续性映射。当前没有管座焊孔；板上的圆分别是玻璃与维修占位。

桌面底座和仪表墙采用同一载架与四个板固定点。前框基准和外壳载荷由载架承担，管座承力方式待确认后与基板分离或补强。管体轴向维修行程至少需考虑插合深度和握持空间；面板开口须实测拔出路径和可触及性。OLED 居中，以独立支架控制目标视角和开口边缘遮挡，不引用未知模组的机械图。C47 朝背面安装，背部应给实际电容高度、端子、线束弯折、拆装工具和隔离罩留空间。防触碰设计需评估正面拔管后的裸露触点、背板开启和仪表墙共用金属件，保留独立绝缘罩与受控维修访问。当前二维结果无法替代外壳干涉和可触及性验证。

## 布局与走线准备

| 区域 | R10 摆位 / 下一步约束 |
| --- | --- |
| 5 V、3.3 V、服务 | 左上，U1 输入旁路及 U2‑L1 优先做短回流。R6 低速电阻，远置仅用于预布局。J2 有 3.3 V UART ROM 维护；USB 不布线。 |
| ESP32 与 RF | 左侧，板载天线部分伸出左边。原厂模块焊盘与板边需分别复核。板天线附近铜、线束及金属壁距按实际外壳参照 15 mm，安装到仪表墙后需做 RF 吞吐测试。库封装的 Ø0.2 mm 热焊盘工艺与默认 Ø0.3 mm 制造限制冲突。 |
| 74HC595 与阴极 | 595 位于中部逻辑分布，阴极开关放背面三个分组。基极回路和发射极回流局部闭合，/OE、时钟及锁存信号远离 SW_HV，并保持连续参考。每个集电极与引脚邻铜须做局部间距核对。 |
| OLED | 中上，连接器在后侧，前框保持载板占位。I²C 拉线需按模组电容验证上升时间、VIL 和可拆线束长度。 |
| HV 升压与储能 | 右上；把 U17/U18/Q32/R73/L3/D3 的功率回路在一次布局中微调，减小 SW_HV 面积。R73 走 Kelvin sense。FB 分压底端与功率路径分开取样，比较器与反馈分别走高阻采样，用干净的 GND 星点。C47、两条泄放和阳极支路需以物理距离保障。 |
| 结构与防护 | M3 孔外侧保留柱体/垫片投影。将金属安装件与板边、HV 铜同时纳入三维间隙。板位太紧时扩大外形、移出机械锚点或采用独立的受保护高压板。 |

[eda/NXT-M3-R10.kicad_dru](eda/NXT-M3-R10.kicad_dru) 施加候选 HV 网络的 2.0 mm 铜间距、SW_HV/SNUB 的 3.2 mm 初筛、HV 铜到板边 2.0 mm、常规铜到板边 0.30 mm、安装孔筛选和 5 V 干线建议。0.50 mm 最小／0.80 mm 目标干线为试布线假设，铜重、总回路压降、环境与 IPC‑2152 热要求须由选厂及真实走线重新估算。

间距来源是污染等级 2、材料组 III、海拔 ≤2,000 m、195 V 上限筛选值、无涂覆取信，候选 2.5 kV 冲击、非均匀场。用旧版 IEC 60664‑1 的表 F.2 作筛查，2.5 kV 对应 1.5 mm 空气间距；F.4 的 200 V 行为 2.0 mm 爬电，设计筛查取最大值 2.0 mm。SW_HV/SNUB 用 320 V 行的 3.2 mm 预留做重复峰值筛查。实际脉冲幅值/频率、外部浪涌、CTI、污染、海拔、实际产品规则和保护等级待定。KiCad 的规则检查铜几何，真实爬电沿材料表面且还涵盖器件本体、开槽、后盖和固定件。100 kHz 开关应另核 IEC 60664‑4，不以工频基线直接签核。SOT‑23 的集电极与低压基/射极已有局部冲突，单纯加板层无法拉开同器件焊盘。需要闭合器件跨压、绝缘结构及标准依据，候选路径为合法的局部绝缘设计、器件变体或分板并重新审查。双层当前只用于密度评估；若地平面连续、RF 和电源回流无法同时达标，应评估四层控制板与物理隔开的高压区域。

参考 [IEC 60664‑1 现行版](https://webstore.iec.ch/en/publication/59671)、[表 F.2/F.4 筛选所用历史版](https://www.iec-equipment.com/Uploads/download/en_60664_1_2007.pdf)、[IEC 60664‑4](https://webstore.iec.ch/en/publication/2804)、[Espressif 布局指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html)、[IPC‑2152](https://www.ipc.org/TOC/IPC-2152.pdf)。
