# R7 基线重建

- 远端为 [langxie29-cpu/QS30-driver](https://github.com/langxie29-cpu/QS30-driver)。2026-11-19 上海时间执行 git ls-remote 和 fetch，R6 远端头匹配请求的冻结 SHA 163a60b2f1525e47b66f929103ff446a3f57c460。R7 在独立工作树从该提交创建，原工作树的未提交内容未移动。
- 使用 R6 原生 [KiCad](../r6/NXT_M3_EDA/NXT-M3.kicad_pro)、[LTspice](../r6/LTSPICE_MODEL/)、[物料](../r6/PRELIMINARY_BOM.csv)、[成本](../r6/DESIGN_TO_COST_REVIEW.md)、[资格](../r6/QUALIFICATION_MATRIX.json)。
- 保留三块同版三位模块。每块独立低压输入、STM32C011F4P6、HV5622PG-G、局部高压和硬件保护。模块间仅走低压 RS-485 A/B/GND，保留 3、6、9 位及三路独立显示协议。
- 原厂 ADI 控制器、ST FET、SiC 及 Vishay SS14 字节按 R6 SHA 校验。R6 冷启 deck SHA 校验一致。LTspice 24.0.12 运行 58 ms，原注册尾窗 49–57 ms 已填全。R6 最初运行止于墙钟预算，见 [原运行](../r6/LTSPICE_MODEL/runs/p1c_full/result.json) 与 [复跑](evidence/runs/exact/)。

常用 170 V 母线负载约为 0.465 W（无管）、0.720 W（一管 1.5 mA）、1.612 W（三管典型）、1.995 W（三管最大）。后两项包含双泄放、反馈、ADC 和 OVP。低压 0.45 W 是独立工程预算。低线 2 W、效率 0.70 时模块输入均流约 0.31 A。DCM 峰流还随 L、频率和实测效率变动，见 [角点预算](POWER_AND_LOAD_BUDGET.csv)。
