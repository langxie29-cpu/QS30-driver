# 三个系统方案

|方案|控制器|电气与架构约束|进入状态|
|---|---|---|---|
|12V-DCM|TI UCC28C43D，外 MOSFET|8.4/7.6V 典型 UVLO，100% 最大占空，独立软启/强制最大占空和故障关断需外电路。与 LT 对比同 L/f 和输入。低成本备选|Round 2 备选审查|
|12V-LT3757A|ADI LT3757AEMSE#PBF，外 UCC27511 与 MOSFET|RT 140k、约 100kHz，原厂 LTspice 宏、SS/UVLO、100–120mV 满电流门限。10.8V 需受保护输入压降和门驱实测|主验证候选|
|24V-LOW-POWER|同 LT3757A 家族重新设计|同输出功率输入均值基本减半，受控占空更低，必须增加 12V 门驱/HV逻辑稳压且重新选择限流窗口；同频峰流改善小|解析对照|

DCM 从每周期二极管平均电流推得 Pout = η×Vo×L×f×Ipk²/[2×(Vo−Vin)]。η=0.75 灵敏度是把总损耗集中折算的近似，损耗无解析拓扑分配。D = L×f×Ipk/Vin，二极管占比 = L×f×Ipk/(Vo−Vin)，两者之和小于 1 才是理想 DCM。边界用 Ipk = Vin×(Vo−Vin)/(Vo×L×f)，不能用 CCM 占空计算 DCM 实际占空。查看 POWER_CORNERS.csv。温度影响以 L ±10%、频率 ±10%、效率 0.70 的预留审查，真实 ESR/DCR、磁芯和开关损耗待验证。冷启动近 Vin 部分可跨入 CCM，输出储能 5µF×170²/2 = 72.25mJ，500mW 净充电时理想 145ms，2W 净充电时 36ms。实际限流、斜坡和输入被动预充均改变该时长。

原厂：[LT3757A](https://www.analog.com/media/en/technical-documentation/data-sheets/LT3757-3757A.pdf) · [UCC28C43](https://www.ti.com/product/UCC28C43)。

## 2W 定量对照

L=150µH、100kHz，L×f=15Ω；η=0.75，低压独列 0.45W。12V-DCM 和 12V-LT3757A 在相同元件假设下共享理想波形，实际控制器损耗、边沿和限流决定差异。

|10.8V|0.289A|0.577A|80.1%|5.44%|2.73W|
|12V|0.260A|0.575A|71.9%|5.46%|3.35W|

|21.6V|0.144A|0.557A|38.7%|5.63%|10.18W|
|24V|0.130A|0.553A|34.5%|5.68%|12.37W|
|26.4V|0.118A|0.548A|31.1%|5.72%|14.72W|

10.8V/2.5W 的低 L×f 与 η=0.70 时峰流 0.742A，距离分流下界约 20mA。高 L×f 与 η=0.70 时按独立 CCM 关系计算，边界约 2.106W；2.5W 会越过 DCM，理想占空 93.65%，反馈斜坡/最小关断时间和 RMS 均需重做。η=0.70 的 lumped 模型是敏感度，不是实测数据。100kHz 在降低频率引起的大磁件与提高频率带来的占空、开关损耗间作初值。低线 2.5W 研究不能用标称 DCM 结论承诺。

独立查表时修正了最初脚本 L×f 的单位展开，改用 H × Hz 的明确乘积并加 15Ω 自检。原仿真网表一直使用 150u，不受角点表早期单位错误影响。
