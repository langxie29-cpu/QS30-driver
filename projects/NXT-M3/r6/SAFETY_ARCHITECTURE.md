# 本地故障链 P1

保险丝和双向 TVS 在 J1；TPS26600 反接与过流开断，开路 MODE 会进入断路器策略，当前 R6 图纸以 402kΩ 将 MODE 连接至 RTN，选有源限流锁存。具体动作边界、过载计时、IN–OUT 压降和反灌需按型号/数据表验证。独立 TPS3700 比较器使用独立 HV 电阻串取样，预偏置 3.3V 供电，硬件锁存分别拉低 eFuse SHDN 与 LT SHDN，并同步抑制门驱。输入开断仍可能存在 Cin 的剩余能量及 L→D 被动路径。接线范围内电源折返、保险丝 I²t、器件 SOA 和 eFuse 同时短失效须单独验证。

双串独立泄放，每支 2×249k，约 58mW/支在 170V。单支开路允许另一条放电。无人工放电依赖。断电残压必须量测确认，产品的可触及性来自完整绝缘防护。主控制电源或辅助电源丢失时门驱 UVLO、LT 引脚许可、HV BL 下拉必须分别验证；Q、D、L 短路/开路与公共地失效不授予 PASS。MCU 有 ADC 监测电路，外设超时只控制显示，独立硬件 OVP 不受固件控制。

OVP 研究点 0.4V×(1+460k/1k)=184.4V；两个 230k 分压器用 0.1%，TPS3700 门槛按全温与分压/泄漏预算复核。许可跳线 DNP（断接令 Boost SHDN 被拉低），作为候选单独隔离手段；生产许可、掉电再启动、手动复位粘连均待审。
