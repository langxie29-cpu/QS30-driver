# 验证计划与退出条件

本文件是后续拟议资格顺序。R6 内只完成软件、工程图纸和仿真。

1. 低压工装，Boost 功率链物理隔离。静态 10.8/12/13.2V，负载阶跃、不供电的 RS-485 节点和掉电/热插拔。记录低压轨、电源流入、总线阈值、各单元地址、误帧/误显示、状态灯、SWD 下载和失联表现。需满足总线共模和电流额定、超时 1s 内消隐，所有设备重连可恢复。数字映射 walking-one 在低压仿真负载逐针核实。
2. 低压故障链替身，阻止产生 170V。独立驱动比较器的缩比输入，记录触发区间、载入的 SHDN/门驱时序、锁存、ARM 卡死/掉电重启/辅助 12V 缺失。验证缩比等价与禁止自动重启，比较器、锁存、eFuse 各有可测引脚，复位需要明确残压许可。禁止用理想 LTspice 开关延迟当实物上限。
3. 设计审查，先收敛波形、样品几何、近场布局以及规则。按用途和目标市场建立绝缘依据，确认 IEC 60664-1 是否适用和使用环境。保护罩、键控、固定方式、有效应力/温升与防触碰能力必须评审。完成真实 PCB 的 DRC 与装配复核。 [IEC 60664-1](https://webstore.iec.ch/en/publication/59671)
4. 未来取得专门授权的高压计划，先由合格人员审查封闭装置、限能夹具、测试方案、测量与联锁。验证输入/负载/温度范围以及冷启、空载、加载、纹波与发热。测 Cmax、最低额定裕量和磁件热态压降、最高开关尖峰与寿命。关闭门槛用 R6 研究范围、安全部件额定和最终冻结规格各自判定。
5. 未来高压合格阶段针对 OVP、输出开路/短路、D/S 短、偏置/门驱失效、泄放支路开路和共享供电传播取得经独立审查的结果。每次记录动作前后 VHV、IIN、关断与可触及联锁。如果任一故障不能限制过冲、能量或功率，回退到硬件候选。195V 是现阶段故障仿真筛选，60V/30V 用于描述残压衰减，触碰安全按适用标准、能量和结构单独认定。
