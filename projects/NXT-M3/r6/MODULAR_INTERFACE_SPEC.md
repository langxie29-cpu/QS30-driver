# 模块接口

|端口|针脚|使用及限值|
|---|---|---|
|J1|1 VIN，2 GND|标称 12V，10.8–13.2V 研究。每块支路保护，电源端禁止互连。优先星形分配或各块独立电源|
|J2/J3|1 A，2 B，3 GND|同一半双工 RS-485 总线进出，120Ω 双绞线与参考地。仅总线物理两端接 120Ω，J8 选择装短接；节点不额外叠加偏置|
|J6|1 ADDR0，2 GND，3 ADDR1，4 GND|各脚独立上拉。两个开路地址 1，接低 ADDR0 得地址 2，接低 ADDR1 得地址 3，同时接低无效。断电配置，启动一次采样|
|J7|1 Vref，2 SWDIO，3 GND，4 SWCLK，5 NRST|3.3V 电平。Vref 是调试器参考，外部调试器按本地供电方式设置|
|J4/J5|内部许可/手动 ARM|J4 候选不装接通件。J5 ARM 始终在防触碰结构内部，维护权限与复位锁止仍需审查|

UART 单端便宜，可用于同板调试，跨模块线缆的共模与掉电反灌预算不稳。CAN 有硬件仲裁和错误隔离，适合多主，需更换本 MCU 或加控制器，主机统筹 V1 不需要。RS-485 用 THVD1410DR 500kbps 级收发器、SM712 阵列、120Ω 可选终端，先研究短线 115200。数据线间及对参考地浪涌、三块同时启动、失电节点泄漏和安规保留。独立电源接参考地时必须接地兼容；未知地差用隔离的系统接口。

共享电源地回流与通信 GND 路径须有明确接线方案，禁止用数据参考线承载常态 12V 支路电流。供电故障和高速拍频测试应独立于协议测试。外部无 HV 针脚。壳体以四只 M3 孔、限位支撑与防触碰罩进入机械验证。
