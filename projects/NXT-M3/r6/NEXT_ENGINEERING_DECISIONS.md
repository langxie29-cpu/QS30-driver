# 下一阶段决定顺序

1. 继续 LT3757A P1 学习；先缩小并定位闭环模型开关事件与实际门驱高频环，补充独立 ESOA、低压 eFuse 负载夹具和全温磁件。保留 UCC28C43D 为明确的第二路径。若 12V 偏置、低线启动或负载恢复的成本/电气门槛未过，同一测试规则用于重新设计 24V 低功率候选。
2. 先冻结保护：明确故障时间/能量，保护偏置失效、残压许可与手动 ARM 的优先级，以可控故障策略限制下游储能。阳极电阻热态和防触碰要求同时冻结。
3. 使用原生 KiCad 10 作为当前源；收到实测管座四视图/尺寸、PQFP 与 TMR 焊盘 1:1 结果后才能收敛 PCB 几何、净类与验证用途。嘉立创专业版若后续正常可用，再做全跨工具逐针验证。
4. 用实际 STM32 工装和 RS-485 线缆完成低压硬件断电、ESD 和重复地址评估。若要求同一数值在全组可确认一致，在 V2 先补确认、断线处理与测试再扩大部署。
5. 首批研究资金按阶段拆开。已有低压工具先复用，若缺低压工装预留 ¥150–450。5 片自装材料/防护/备板计划项为约 ¥1,878–3,715，实际物料、THT、运税、共用主机/电源和实验设施未报价。采购与制造保持 HOLD。不要用不具备库存的 P1 购物篮锁定预算。
