# 原生 EDA 验证

KiCad 10.0.8 CLI 实际读取 NXT_M3_EDA/NXT-M3.kicad_sch，在完整层级直接做 kicadxml 导出、ERC JSON 和 PDF 导出。初版将 TPS26600 两个并联输出脚都给 power_out 类型，ERC 发现电源引脚冲突，现保留脚 23 电源输出角色、脚 24 表示并联焊脚。KiCad 10 库表需 (lib 后分隔空格。按原生语法改图纸生成器后，本地符号/封装库成功取用。

最终 ERC 0 错误、0 警告。原生网表 120 个器件/机械/接口实例、135 网络，逐槽比对 418/418，30 个独立阴极、3 个独立阳极，HV170 与模块外部端口隔离，驱动未用 HVOUT31/32 和 DOUT 显式 NC。418 槽含 4 个 ERC source 声明，数量以 evidence/eda_audit.json 为准。对 U12 与三管座，复核源采用冻结历代引脚表，再查 Microchip PG 引脚和外形。分立器件脚位、其他 IC 和安装件有图纸数据表依据，工装脚位实测待完成。

117 个有候选封装的原生导出与实际 KiCad 库焊盘集合一致，三管座未指定几何封装。U12 选 10×10mm、0.8mm 间距、约 13.9mm 跨距的 Microchip PQFP PG。TMR 的候选封装为原厂标称机械图的自有 KiCad footprint，仍需 1:1 叠图、引脚观察面及样品核定。未建 PCB，未执行 DRC。专业版沿用 R5 已实测的官方转换器应用控制阻塞及客户端激活阻塞，当前以 KiCad 为权威图纸。
