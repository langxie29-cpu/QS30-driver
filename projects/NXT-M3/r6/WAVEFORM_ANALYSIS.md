# 原生 LTspice 波形与证据

环境为 LTspice 24.0.12 Windows。相同 ADI 原厂 LT3757A 和未经修改的 R4 ST FET、SiC/Vishay 模型从冻结来源重用。模型以每次 SHA 固定。控制器、半导体厂商模型的可适用范围沿用 R4，使用者需自行取得。输入前级为开关近似，独立 OVP 用行为状态代理，驱动为电压近似，线性磁芯、DCR，管为等效电阻。外驱真实延时、偏置损失、开断、管起辉/维持、电感饱和、寄生与电热均未合入。

- 完整 12V 冷启动首个调用发现原厂 SiC 是 D 模型，X 实例无法解析。保留 MODEL_FAIL 和日志。修复后 P1/P1b 约在 32.7–32.9ms 因墙钟限制结束，末采样 164.94–165.36V。未取到稳态，不能将进程失败或启动片段算成电气 PASS。
- 23ms 原生冷启单元在 140.42V 结束（有界窗），P1c 全运行在 37.472ms、170.420V 时到墙钟限制，注册尾窗尚未到达。三角点 FET 代用在 56.2–59.7ms 约 169.77–170.08V 处超时，也没有到达预注册尾窗。代用固定变阻和 C，不代表厂商 FET 的热态或开关应力。
- 热/最大负载预充了 170V 且控制器冷起。10.8V、2.5W、85°C、135µH 下 4ms 到 157.16V，说明在该窗口未建立负载。此轨迹不足以得稳态 2.5W。12V 1.1475→1.53W 的有限窗末点 161.98V，10.8→13.2V 有限窗末点 163.60V。不能据此判定完整恢复时间和纹波。
- 成对的 500/250ns 最大步差异在温启动负载轨迹的末点不到 0.001V，但负 VGS 极值分别 −8.26 和 −6.35V，峰值敏感。热角点代理 VDS 峰约 169.92V、整流器反压 170.54V、IL 0.337A 都只限所跑窗口。明示前充窗口测的电容 RMS 约 27–45mA，不是全电路最坏值。未取得定量开关耗散资格。以 170V、0.6A、100kHz 和单边 50–200ns 分析重叠，约 0.26–1.02W，说明不能忽略开关损耗。
- 初始内部 ESR/ESL 与 C 的 170/195V 预充条件制造了 366–409V 的开端伪峰。保留反例，基于外置 ESR、端点一致 IC 的诊断重做，此变更不证明真实寄生安全。
- 独立模型以 186V 预充已过比较门槛，代理锁存在 5.85µs 后动作，虚拟输出峰 186.17V。5ms 反馈注入轨迹未触发 OVP，因此闭环故障过冲和实际最大动作时间保持未决。
- 5.5µF、195V 的独立 RC 单元运行到 4s。双路约 1.611s、单路 3.229s 到 60V。PWM 不开时，12V 可通过真实 SiC 二极管和 L 向 1kΩ 诊断负载提供 11.1406V。理想开断时约 0.12mV。R6 放电不能只依赖 PWM 关断。
- 23ms 与完整尝试使用不同数值设置；对大波形按原始字节保留。早期测量解析把 WHEN 门槛值错取为时间，附未改写的初次收据和在汇总脚本用 AT 字段的修正。原首测类型更正为 MODEL_FAIL，ESL 预充伪峰的 diagnostic_decay 以 INCONCLUSIVE 评定。

逐运行命令、SHA、端点及最终分类见 [SIMULATION_RESULTS.csv](SIMULATION_RESULTS.csv)。任何 LIMITED_PASS 都只适用于所描述的机制。
