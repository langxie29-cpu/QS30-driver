# Σ / NXT R9 产品需求

2026-11-20 · Gate 0 REWORK · ENGINEERING HOLD

## 冻结决定

| 条目 | 要求 |
| --- | --- |
| 产品 | 三块可独立工作的三位模块。每块 PCB、BOM 架构和固件相同，身份与显示位置由配置赋予。 |
| 数值 | 每块 3 支 QS30-1，静态显示，30 个阴极各自可控。4 片 74HC595，2 个空余输出保持零。每路一颗经资格验证的国产 MMBTA42，共 30 颗。 |
| 连接 | 每块 1 个 ESP32-S3-WROOM-1，独立接入 Wi-Fi。RS-485 从必装 BOM 移出，可研究默认不装的扩展焊盘。 |
| 语义 | 三管上方放一块横向单色 OLED。优先红色，其次琥珀橙，黄色仅经用户批准后用于正式产品。RGB 不具备正式替代资格。优先 I²C，各驱动可独立适配。 |
| 电源 | 每块独立 5 V 输入、3.3 V 逻辑轨及约 170 V 本地高压域。模块之间只需 Wi-Fi 互通。 |
| 安全 | 每块独立具备输入切断、OVP、故障锁存、泄放、残压联锁及防触碰。故障下的短暂残光可接受，条件是应力、热、接触风险及重复故障门槛全部满足。 |
| 显示模式 | 独立三位、任意合规两块六位、三块九位。OLED 和管数字来自同一事务。任何跨节点同步都按可测的误差和失效界限验收。 |
| 成本 | 每块长期 ¥60，阶段 ¥80–100，含 Wi-Fi、OLED、保护、管座及 PCB，已有管、外壳及人工排除。首次现金、复购材料和委外制造分别列账。 |

冻结项包含 Wi-Fi MCU、独立供电、30 路及静态显示、单色 OLED 和保护目标。本轮在 Gate 0 下只做分析与隔离低压逻辑工作。完整高压板制造和实物高压试验维持 HOLD。

## 待确认与工程暂定

- 首件推荐 2.23 英寸橙色。黄色是否接受、使用距离、字符语种、样机面板尺寸和视觉验收阈值待用户确认。
- 样机暂按模块连续输入 4.4–5.25 V、5 V/1.5 A 级电源做电预算。5 V 正式接口、电源最小宣告电流、线缆压降和插拔浪涌待实测。
- 选择 ESP32-S3-WROOM-1-N8 作为设计候选。部署、联网凭据与配网流程需要实物原型确认。
- QS30-1 无专用小数点和负号。本轮用 OLED 的单位行标注小数位置，量程为非负，补空规则见协议。是否需要带符号值及其他格式属下一产品决定。
- 温度/污染等级、绝缘与接触限值、维护联锁阈值、支路异常检测及电容最终容量仍属于资格审查。
