# S06B 单元资格续作方案

2026-11-15，Asia/Shanghai。接续S06，仍是S06电气/模型资格工作，不进入PCB阶段。07不通过则不进入08；不预充170V、不扫闭环、不采购、不生成制造包、不实物高压上电，制造HOLD。

执行顺序与预登记：

1. 保存当前S06/S05输入哈希与工作区状态；不覆盖任何旧run。复现原1ns崩溃与联接失败，逐例保留命令、原日志、终点及波形。执行合格要求rc0、无abort/timestep-too-small、有限数据和原生终点；不能用rc0代替成功。
2. 区分仿真器/模型问题：相同1ns夹具重复三次；联接原夹具对照100Ω输入隔离、START/STEADY子模型。后两者是明确的电路/模型范围变化，不能用STEADY通过宣称启动通过。必要时用已安装的KiCad共享ngspice引擎做独立构建对照，不改变原厂电气数值来强行收敛。
3. 取得ST精确器件原厂模型/资料和磁件热态曲线；记录原厂模型不包含的效应，缺失时提出有来源的替代器件候选。热态无证不以25°C值放行。
4. 审查S06正常峰流与损耗分配是否一致，建立启动/跨模式的明确策略边界。只做单元、解析及开环/受限能量夹具；07不足时不接闭环。
5. 执行PG/复位掉电、半供电、传播延迟与USB启动资格检查。区分真实原厂模型、明确保守边界夹具与待实测数据；检查最坏跌落/枚举条件，不能把布尔真值当器件动态。
6. 汇总实际解除与未解除项，更新参数增量/证据矩阵/报告/断点。失败保持原样。满足全部07门槛才决定进入08，其余保持HOLD。

预定交付：原失败复现/定位记录、模型适配差异与来源、损耗/峰流/热态/启动策略审查、PG和USB资格结论、运行矩阵/原始文件/完整性记录及新的接续断点。本方案先于新单元执行建立；具体运行目录另存参数与判据。
