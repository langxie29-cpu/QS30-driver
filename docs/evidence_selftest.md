# 证据校验框架自测（合成数据）

> 本文件由 `design/evidence_selftest.py` 生成。所用数据为**合成数据**，唯一目的是证明校验器能识别「未提交/部分/完整/失败」四种状态，**不代表实物测试结果**。

## 1. 模板原样（未提交）

- 退出码：0（期望 0，无失败项）
- 结论：正确识别为未提交

## 2. 合成数据全部合法

- 退出码：0（期望 0）
- 结论：7 项 HOLD 均判为已提交且通过

## 3. 注入 3 处非法值

- 退出码：2（期望 2）
- 结论：校验器成功捕获（H02/H04/H06 判据失败）
