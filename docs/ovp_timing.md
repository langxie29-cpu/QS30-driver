# OVP 时序回归：复位脉冲宽度 + 锁存保持

- 模型：`sim/boost_ovp_logic.cir`（行为保护逻辑），步长 20 µs，仿真 900 ms
- 场景：反馈断路故障使输出升到 OVP；0.6 s 发一次复位脉冲（宽度扫描）；故障不消除时观察是否再次锁存。

## 结果

| 复位脉冲宽度 | 首次触发 (ms) | 释放锁存 | 释放时刻 (ms) | 再次锁存 | 最大电压 (V) | 最终锁存 |
|---|---|---|---|---|---|---|
| 无复位 | 1.14 | 否 | — | 否 | 201.28 | 是 |
| 0.2 ms | 1.14 | 是 | 600.28 | 是 | 201.45 | 是 |
| 0.5 ms | 1.14 | 是 | 600.28 | 是 | 201.45 | 是 |
| 1.0 ms | 1.14 | 是 | 600.28 | 是 | 201.45 | 是 |
| 2.0 ms | 1.14 | 是 | 600.28 | 是 | 201.53 | 是 |
| 5.0 ms | 1.14 | 是 | 600.28 | 是 | 201.92 | 是 |
| 10.0 ms | 1.14 | 是 | 600.28 | 是 | 201.92 | 是 |

## 结论

- **不复位时锁存保持**：是（0.05 s 之后一直保持，输出安全泄放）
- **可靠复位的最小脉冲宽度**：**0.2 ms**（更窄的脉冲可能无法释放锁存）
- 复位后再次锁存：是（故障未消除时应再次保护）
- 工程含义：MCU 复位脉冲需 ≥ 该最小宽度；固件应在 HV 低于 OVP 阈值后再执行复位，否则复位无效（等价 SCR 在 OVP 有效时不可关断）。

## 边界

本模型为行为级（非器件级 SCR）：忽略维持电流、门极触发延迟、结温与 dV/dt 误触发；上述时序窗口必须 H06 用实物验证并回填 `docs/evidence/H06_hv.csv`。
