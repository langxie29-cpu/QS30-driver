# A9.2 仿真模型边界

执行器是官方 ngspice 47 Windows console；来源、SHA256、初始未安装状态见 environment.json。
模型及脚本为本工程原创，按工程仓库许可使用。没有把厂商模型文件改名为自建模型。
每个 circuit.cir 都能在其目录下用 `ngspice_con.exe -b -o replay.log circuit.cir` 独立执行。

输入引脚与R/C/L值从各次原生 XML 和对应 CSV 取得，输入哈希在各run/results.json。
模型包含实际分立Q21/Q22/Q25，不使用理想数字锁存器替代它们。

`mode=injection` 使用明确标出的 VFAULT 强制母线电压，以独立检查OVP极性、滤波和锁存。
其230V峰值来自注入源，**不是受保护升压器的峰值**，关断不能移除该理想外部源。
不能由这些曲线宣称220V HV5622推荐上限或230V绝对最大值的裕量合格。

`baseline` 首次电流向量导出失败；`a9_2_actual` 在1.002ms发生UVLO模型无迟滞引起的步长错误。
后一run的旧解析器曾因ngspice返回0而错误写PASS，已在 invalidated_runs.json 明确作废，原日志/JSON/曲线不删除。
最终解析器必须同时检查rc、错误/aborted文本和meas end_time到达终点，不能仅检查返回码或linearize补出的终点。
`baseline_repaired_vectors` / `a9_2_uvlo_repair` 为中间诊断模型；最终直接对比使用带D4、UVLO迟滞及终点检查的同一模型。

所有工程结论仍受实际原生电路CS错误和锁存无限流限制。SPICE执行PASS与保护工程PASS是两列；当前保护不通过。
