## 1. 开关级功率级 SPICE（`04_boost_power_stage.cir`）

固定占空比 D=0.73（该负载下 DCM 工作点占空比）、初值=工作点，六管等效负载 12.3 k：

| 项目 | SPICE | 解析/理论 | 偏差 |
|---|---|---|---|
| 稳态输出 | **171.99 V** | 171.95 V（DCM 公式） | +0.02% |
| 电感峰值 | **503 mA** | 510 mA | −1.4% |
| 输出纹波（单周期） | **8.7 mVpp** | 9.0 mVpp | −3% |
| 效率（h=10 ns） | **95.9%** | 器件损耗估算 ≈96% | — |

- 步长敏感性（50/20/10 ns）：纹波/峰值几乎不变；效率 90.0→94.4→95.9%（后向欧拉数值阻尼）。
- Coss 敏感性：开关节点 100 pF 时效率 **95.9%→91.0%**（增加损耗 ≈½CV²f≈115 mW）
  → 2.6 W 输出下是 5 个百分点，**必须选低 Coss 器件并实测（H06）**。

## 2. 平均模型闭环（`boost_averaged*.cir`）

开关级闭环需 ≈13000 个开关周期（>10⁶ 步）才稳定，超出纯 Python 求解器算力；
因此用**平均模型**（去掉开关纹波、保留能量关系与同一组控制参数
CINT 22 µF / Ki 1.3e-4 / Kp 0.05）：

| 项目 | 结果 |
|---|---|
| 稳态输出 | **172.18 V**（误差 3.3 mV；理论 2.5×(1+1500/22.1)=172.18 V） |
| 稳态占空比 / 电感平均电流 | **0.931** / **219 mA**（= Iout/(1−d)，自洽；峰值 300 mA） |
| 输出电压范围（稳态） | 172.00–172.33 V（阶跃模型负载下探 3.9 V） |
| 负载 +50%（0.15 s） | 下探 **0.25 V**，恢复 **<1 ms**（电感电流快速跟随） |
| 输入 12→11.4 V（0.30 s） | 下探 **3.90 V**，恢复 **8 ms** |
| 输入阶跃 12→11.4 V | 最终误差 ≈3 mV |
| 闭环判据 | **8/8 通过** |

- 边界：初值取工作点（**启动暂态由行为模型 S1 覆盖**）；不含开关纹波/器件应力（由第 1 节覆盖）；不含 OVP 锁存（行为模型 S7/S8 覆盖）；
  UC3843 实际补偿 R72/C56 的相位裕度需 H06 实测。
- 输入阶跃恢复 8–9 ms、下探 4.1 V 是当前 PI 参数（CINT 22 µF）的结果；静态显示时每管恒有
  1 路阴极导通、负载变化很小，因此可接受。

## 3. OVP 保护逻辑（`boost_ovp_logic.cir`）

把升压级等效为限流受控电流源 + 输出电容（保护逻辑的时序/阈值验证；不含电感/开关动力学）：

| 项目 | 结果 |
|---|---|
| 首次 OVP 触发 | **198.92 V**（1.14 ms，阈值 198.8 V） |
| 触发后 | 锁存（latch≈1）、EN=0、转换器关断 |
| 泄放 | 0.3 s 时 123 V（<150 V 判据） |
| 受控复位 | MCU GPIO18 脉冲使锁存释放（仅当 HV 已低于阈值才有效，等价 SCR 不可在 OVP 有效时复位） |
| 故障未消除 | 复位后再次升到 198.8 V → 再次锁存 |
| 全过程最大电压 | 201.9 V（≤205 V 判据） |
| 判据 | **7/7 通过**；波形 `sim/results/spice_ovp_latch.png` |

边界：不含 SCR 器件级非理想（维持电流/触发延迟/结温），器件级与实物时序仍须 H06。

## 3.5 环路参数敏感性扫描（`design/loop_scan.py`）

27 组 CINT/Ki/Kp，输入 12→11.4 V 阶跃，测量下探/恢复/末段振荡：

| 参数 | 输入阶跃下探 | 恢复（±1%） |
|---|---|---|
| BOM 参考（CINT 22 µF / Ki 1.3e-4 / Kp 0.05） | 4.10 V | 9 ms |
| Kp 提至 0.15 | **2.1 V** | 2 ms |
| Kp = 0 | 8.2 V | 8 ms |
| CINT 47 µF + Ki 6.5e-5 + Kp 0.15 | 2.2 V | 2 ms，但**末段振荡 95 mV（不稳定）** |

结论：**比例项（Kp）主导下探**；Ki 过小 + CINT 过大 + Kp 大 → 振荡边界。扫描只给趋势，
R72/C56 最终取值必须 H06 实测相位裕度确定（详见 `docs/loop_scan.md`）。

## 3.6 OVP 时序回归（`design/ovp_timing_scan.py`）

复位脉冲宽度扫描（0/0.2/0.5/1/2/5/10 ms）与"不复位"保持测试：

| 项 | 结果 |
|---|---|
| 首次触发 | 1.14 ms @ 198.8 V（各脉宽一致） |
| 不复位时锁存保持 | **保持**（0.9 s 内 latch 恒 >0.9，输出安全泄放） |
| 可靠复位最小脉宽 | **0.2 ms**（本模型 20 µs 步长分辨率下） |
| 复位后（故障未消除） | **再次锁存**，最大电压 201.3–201.9 V |
| 最终状态 | 锁存/关断 |

工程含义：MCU 复位脉冲需 ≥0.2 ms，且必须在 HV 已低于 OVP 阈值后执行（OVP 有效时复位无效，
等价 SCR 不可关断）。器件级维持电流/触发延迟仍须 H06。

## 7. 模型局限（必须与结论连读）

1. 不是器件级 SPICE：开关损耗、寄生振铃、二极管反向恢复、磁芯损耗、温升均未建模；
2. minispice 的一阶后向欧拉有数值阻尼（已做步长敏感性与解析解自检）；
3. 平均模型不含开关纹波与器件应力；
4. 起辉按 150 V 建模、管子压降按 125 V（原厂参数范围），实际批次需 H02 实测；
5. 一切结论以 `HOLD_REGISTER.md` 的关闭证据为准，仿真不能替代实物测试。
