# 高压驱动方案比较（90 路静态）

设计需求：9 管 ×10 阴极 = **90 路**独立开漏输出，静态驱动，无扫描。

| 指标 | A: 3×HV5622PG-G | B: 74HC595×12 + MPSA42×90 |
|---|---|---|
| 器件数量（芯片/晶体管） | 3 | 12 + 90 |
| 焊点估算（仅主要器件） | ~132 | ~642 |
| 布局面积估算 | ~675 mm² | ~1080 mm² |
| 时序 | 96 bit 级联，100 kHz | 12×8 bit 级联，需额外锁存/使能 |
| 高压瞬态/泄漏 | 芯片规格内（Vpp 220 V） | 需逐管验证 MPSA42 关断/泄漏 |
| 维修 | 换 1 颗 PQFP-44 | 换 90 个分立元件中的某一个 |
| 价格 | 3×32.15 元（UNVERIFIED） | 未询价（UNKNOWN） |

## 推荐：方案 A（HV5622PG-G ×3）

理由：焊点/布局/维修点少一个数量级；每片 30 用 2 备；引脚表已验证。分立方案只有在 HV5622 实际采购价远高于分立总价、且能完成 MPSA42 高压验证时才考虑。

**未决**：HV5622 真实渠道价/库存/真伪必须询价确认（P2-02）；PLCC-44（PJ-G）若更便宜且可得，可作为 BOM-A 备选，但必须重建 PLCC 引脚表与焊盘。
