# Sprint 03 — TOPOLOGY_FEASIBILITY

结论：**实际器件架构 UNKNOWN，HV-G0 BLOCKED。** 常规 Boost 的转换比没有证明为物理不可能，但当前接线不可作为有效峰值电流模式电源。关键器件和输入尚不足以支持 FEASIBLE，也不能把模型固定92%上限推广成所有 UC3843AN 都 INFEASIBLE。

## 1. 从实际工程确认拓扑

本轮 KiCad10.0.8 从两套当前 `.kicad_sch` 重新导出 XML（rc0），并核对 MAIN 64 个高压相关引脚，参见 `../../sim/sprint03/native_export.json`、`native_topology.json`、`native_hv_pins.csv`（完整路径入口见总报告）。原理图采用自定义符号，DesignRef 与 KiCad 排序引用不同；所有本报告引用均为 DesignRef。

HV_IN→L20(220µH)→SW_HV；Q20.D=SW_HV、S=GND，D20.A=SW_HV、K=HV_BUS。没有磁耦合、变压器或倍压级。U20.OUT直接连接HV_GATE，VCC=HV_IN，FB=R34/R35分压，COMP为R37/C14/C15与故障拉低节点。实际无源极分流；R36从SW_HV到CS，C13到GND。**控制器支持峰值电流模式，当前连接没有实现有效电流模式。** 不能把错误CS看作正常电压模式控制，因为没有经过设计的载波/电压调制路径。

单一母线供左/中/右模块；中央三管在MAIN板内，左右共用DISPLAY模板，各有本地电容和泄放。GND_HV通过MAIN唯一0Ω星点回GND，非隔离架构。管阴极回流通过HV5622/VSS/LV地，不是通过单独高压回线形成隔离负载。

## 2. 目标和负载来源

172 V来自反馈**2.5×(1+1500/22.1)=172.183258 V**，不是管子必须精确172V的原厂指标。原厂扫描给Ea170V、20k、1.5/2.25/3mA；真实维持压、起辉迟滞、驱动压降未测。旧模型125V维持压是ASSUMED。

九管最大27mA，在目标电压时4.64895W。四支200k泄放合成50k，额外3.44367mA/.59294W；正常反馈与OVP分压额外.22647mA/.03899W。由此高压侧约**30.670mA/5.28088W**，不含漏电、故障支路与低压系统。静态九管2.25mA对应高压侧约4.119W。原POWER9的3.49/4.65W仅是管支路功率，不能当转换器完整输出预算。

11.4/12/12.6V来自历史探索集合，**没有适配器厂商/额定电流/容差证明**。以下Vin定义为电感输入端；适配器到此还有保护二极管、开关、保险/线束压降。额外10.9V列只展示0.5V压降的影响，不冻结其压降为事实。

## 3. 可复算损耗筛查

详细数字由 `design9/sprint03_report.py` 生成在 [calculations.json](calculations.json)。定义q=1−D，满载输出Io=.0306701A，假设L=220µH、DCR=.3Ω、MOS=.55Ω、候选源极电阻=.15Ω、二极管Vf=1V、fs=78kHz。

电感平均伏秒平衡与电荷平衡近似为：

```
Iavg = Io/q
Vin = q*(Vo+Vf) + (Io/q)*[rL + D*(rMOS+rS)]
(Vo+Vf)*q^2 - [Vin+Io*(rMOS+rS)]*q + Io*(rL+rMOS+rS) = 0
ΔI ≈ [Vin−Iavg*(rL+rMOS+rS)]*D/(L*fs)
Irms ≈ sqrt(Iavg^2+ΔI^2/12)
```

选择较大q、低电流根。电阻压降采用平均电流近似；不包含换流损耗、温升、饱和和输入串联器件。没有拟合一个效率以得到目标。

CCM边界输出电流约19.65/21.78/24.01mA（11.4/12/12.6V）；最大含附加负载30.67mA进入CCM，典型23.92mA在高输入接近DCM边界，空载/轻载为DCM。因此93%关系不能直接推广到所有轻载工况。理想92%上限且低输入时，满载条件下没有足够增益（CCM理想142.5V），但这不等于实际AN器件都只能92%，也不排除降低负载时DCM的不同关系。

## 4. 控制器与时序证据

当前CSV/BOM明确写 **UC3843AN / DIP-8**；供应商未冻结，不能继续记成“无后缀UC3843”。[TI订购页](https://www.ti.com/product/UC3843A/part-details/UC3843AN)把它映射至A系列PDIP8。当前实际封装仍QS30:PRELIM_8P，不是经核对的PDIP实体焊盘。

条件性参考 [TI SLUS224H Rev.H](https://www.ti.com/lit/ds/symlink/uc3843a.pdf)，5.5表pp6–7：A系列DMAX为92/96/100%，旧94%最小值已在修订记录改为92%；测试条件15V、RT10k、CT3.3nF，不能移植成12V/2.2nF下保证。A系列放电电流标称8.3mA，UC384xA全工作范围7.6–8.8mA（规定CT电压条件）；上一轮6mA模型不是AN的名义参数。UVLO与CS阈值/延迟见矩阵和本地原始PDF，均不是本轮实际芯片测量。

常见频率近似fs≈1.72/(RT·CT)=78.18kHz；精确频率/死区取决于阈值和放电电流。[TI DN40](https://www.ti.com/lit/an/slua173/slua173.pdf)解释其依赖关系，不能把文中另一器件的例子电流当作本器件上下界。

本轮继承功能模型仅将IDIS设为8.3mA，基准得到78.948kHz、最大占空96.378%；7.6/8.8mA敏感性约96.04/96.62%。**该结果不是规格保证**：其固定阈值、理想迟滞和求解步进没有覆盖量产分布，甚至不重现手册保证最小DMAX92%。模型名仍保留UC3843_FUNC，未冒充厂家AN模型。

所需关断时间约.81µs；频率升高会进一步缩短。必须给放电死区、驱动传播/下降、Miller平台、二极管恢复和电流检测留预算。CS比较器规定阶跃条件下最高300ns响应并不能与其他独立上限简单拼成精确开关延迟。实际门极电压也随VCC/输出负载变化，Vishay .55Ω的10V栅压条件在低输入下尚未证明成立。

Vishay比较件Qg(max)63nC时78kHz平均栅极充电电流约4.91mA，12V充电能量量级.059W；Qgd32nC若平台驱动只有.2A需约160ns。这是手册规定不同VDS/ID测试点的量级参考，不能当实际小电流换流时间保证。现有1nF门电容和理想驱动没有表示这些效应。

## 5. 应力、热和补偿约束

正常静态MOS VDS约Vo+二极管压降，二极管反压约Vo；实际峰值必须再加Lpar·di/dt、非线性Coss、二极管恢复与布局寄生。**不使用任意15%尖峰余量替代仿真/测量**。400V/1000V/250V是设计家族标签，真实厂家、热/SOA、降额要求未闭合；保护上限还受HV5622推荐220V约束。OVP静态192.5–204.5V历史目标不包含动态峰值保证。

20.3µF的理想电容纹波约18mVpp；ESR附加纹波和换流尖峰未包括。目标储能约.301J。C10不是普通到地旁路，而是跨SW/输出10nF；在172.18V、78kHz下单次硬换向½CV²f量级**11.56W**，两边沿的总损耗取决于能量恢复路径，不报告精确热损耗。必须单独核查它的功能/换流能量，不能把模拟中去掉C10授权为正式删除。

简单电阻负载CCM的RHP零点估计fz=Rload·(1−D)^2/(2πL)，低输入约16.2kHz。实际管负载非线性，工作模式转换，且斜坡内环未知，因此此数不作为已测环路。建议带宽先小于fz/5，最终用有效小信号/注入法核对；本轮未进行不可信AC线性化，不报告相位裕量。

峰值电流模式>50%需要斜坡补偿。若假设.15Ω分流、1k/2.8k求和，在11.4→172V下简单离散稳定条件 m_a>(m2−m1)/2；以CT末段斜率2.3/(10k·2.2n)计算，直接CT求和的约.0275V/µs低于所需约.0375V/µs。BJT射随器的VBE/动态增益与CT负载还需计入，缓冲恢复振荡不等于斜坡或限流合格。本轮没有继续扫描补偿阻容。
