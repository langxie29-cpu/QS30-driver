# COMPONENT_MODEL_MATRIX 阅读说明

逐参数可筛选矩阵为 [COMPONENT_MODEL_MATRIX.csv](COMPONENT_MODEL_MATRIX.csv)，共20项，含数值/单位、设计引用、厂商来源、状态、模型实现和阻塞影响。

**CONFIRMED 表示在指定工程文件/原厂扫描中确认的设计输入，不代表已采购实物、厂商身份或实体封装已确认。** ASSUMED表示研究条件；UNKNOWN表示没有可靠输入。一个组件设计标签已确认，不会使其所有未给出的参数自动变成真实规格。

本轮最重要的版本差异：

- U20当前CSV和BOM写UC3843AN，DIP-8；TI官网有这个确切订购码且属于UC3843A。历史报告泛称UC3843并用SLUS223H；本轮增加SLUS224H，保留两份原始来源。实际制造商仍未记录，不默认指派TI。
- A系列放电电流8.3mA与历史功能模型6mA不同。本轮只做明确标注的A系列时序假设，未声称获得厂商模型；新版手册DMAX保证下限仍是92%。
- 原工程CS为100k/470p从SW采样，研究候选才有.15Ω分流及1k/100p。不得把候选的功耗/阈值列当实际实现。
- 原补偿100nF支路到地、22µF COMP到地；历史Type-II为4.7µF/1nF返回FB。它们不是同一网络。
- C11/C12主板20µF与加三模块后20.3µF分开；泄放主板200k与全连接50k分开。
- BOM的VERIFIED字段不等同本轮模型可信度签核，原生实体焊盘目前均PRELIM。旧BOM有滞后，连接/数值以当前原生XML与CSV逐脚比对为依据。

阻塞清单与影响：

| 缺失输入 | 影响结论 | 所需证据 |
|---|---|---|
| 适配器完整型号、最小/最大电压、额定/限流、瞬态、线缆 | 最坏输入、启动UVLO、整机功率预算 | 原厂规格及系统输入定义；明确在哪个节点规定电压 |
| U20制造商/订购码确认、温区、RT/CT公差与驱动负载 | 有效DMAX、死区、VGS、CS阈值/延迟 | A系列确切手册及选定条件下的可支持保证/后续低压表征计划 |
| L20完整型号、DCR/温漂、Isat定义与曲线、Irms | 增益、过流、启动峰值、热 | 原厂磁件资料及饱和模型 |
| MOS/二极管确切供应商、后缀、换流模型 | VDS/ID/Qgd/反向恢复/应力/损耗 | 原厂电气模型或可验证的有限模型边界 |
| 电容/采样/高阻/泄放实体型号、公差、ESR/ESL/额定 | 纹波、寿命、限流/过压、单故障放电 | 实体BOM、温度/电压/功率规格 |
| 管子工作点分布、允许输出/纹波/启动/过冲及降额批准 | G1正式验收与合理负载范围 | 设计签审；本轮不进行实体高压上电 |

建议阈值均 **PROPOSED**：稳态172.18V±2%，输出端≤1Vpp；连续三个10ms窗口、每窗周期平均漂移≤.1V且拟合斜率≤10V/s；100ms内进入窗口；过冲≤目标+5%；正常峰流预预算≤1.5A但必须由真实Isat/SOA重定；MOS/电容正常最高工作电压≤额定80%并同时受下游220V及瞬态预算约束。理由分别为显示工作点、可分辨的稳定性、启动体验、储能与降额余量。这些不是已批准规格，不用于本轮宣布工程PASS。原169–175V、晚窗口<2Vpp等研究判据也未找到明确批准记录。
