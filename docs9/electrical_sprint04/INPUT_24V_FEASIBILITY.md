# Sprint 04 — 24V输入、170V高压与低压供电方案推演

日期：2026-11-14（Asia/Shanghai）。结论等级：**分析筛查支持24V作为优先研究输入；未通过器件级仿真、实物验证或设计放行。** 本文不修改正式原理图/PCB，也不将旧系统FAIL升级。

## 1. 功率规模与架构结论

在170V母线、九支管各3mA的规定负载假设下，管支路从母线取得4.590W；加四支200k泄放及反馈/OVP/ADC三路分压，合计约**5.2251W / 30.7359mA**。这不是九管本体耗散，也不是整机输入功率；实际工作电流仍由管压降、阳极20k及驱动压降共同决定。详细核查由并行POWER_BUDGET_9TUBE报告承担。

因此24V供约5W高压侧在能量规模上可行，输入平均电流比12V约减半；但不意味着现有工程直接换适配器即可工作。现有控制器CS接线错误、保护FAIL、C10跨开关二极管换向、器件未冻结等问题不因升高输入自动消失。

**建议研究架构：24V受保护输入分成三路：24→170V高压Boost、24→约12V驱动/控制辅助轨、24→3.3V逻辑轨（或保留24→5V→3.3V以兼容USB供电）。** 只有3.3V和170V两条内部电源不足以兼容现有HV5622。

## 2. 占空比必须先区分CCM/DCM

计算脚本：[topology24_sprint04.py](../../design9/topology24_sprint04.py)，完整40个点：[topology24_calculations.json](topology24_calculations.json)。以下Vin均为**电感端**，未计适配器至电感的保护/线缆压降；±5%/±10%仅研究包络，非已冻结电源规格。研究沿用线性220µH、78kHz，理想无损开关/二极管，170V、最大30.7359mA输出。

CCM转换比为D=1−Vin/Vo，但对24V不能直接当作实际工作占空。临界输出电流：

```
Io_boundary = Vin²(1−Vin/Vo)/(2 L fs Vo)
Lcrit = Vin²(1−Vin/Vo)/(2 fs Vo Io)
DCM: D = sqrt[2 L fs Io (Vo−Vin)]/Vin
D2 = Vin D/(Vo−Vin); Ipk = Vin D/(L fs)
Iin_avg = Ipk(D+D2)/2; idle = 1−D−D2
```

这些由电感电流三角形和输出电荷平衡推导；脚本逐点核对Vin×Iin=Vo×Io及模式条件。TI也将DCM定义为电感电流每周期归零且有空闲区的模式，[TI Boost模式说明](https://www.ti.com/document-viewer/lit/html/sluaao8)。没有将简化公式当作非线性器件仿真。

24V时临界输出约84.79mA，明显大于九管满载30.74mA，所以220µH下全正常管负载及消隐研究点均为DCM。名义DCM二极管导通约1.090µs，空闲约5.101µs；**6.191µs总关断时间不等于二极管有效传能时间**。即使另选较大L进入CCM，转换比参考关断约1.810µs也较12V翻倍。

24V不会把峰流减半：本理想模型峰流仅0.760→0.723A，平均0.435→0.218A，RMS约0.474→0.324A；导通损耗趋于改善，但效率仍需真实开关、恢复、C10、磁损和控制耗电验证。不能用“平均电流减半”把分流/限流或磁件额定也减半。

12→48→170V两级的低输入11.4V **CCM转换比参考**为76.25%和71.76%，两级实际模式分别取决于各自L/fs及功率，不沿用单级220µH模型或声称这些是两级实际占空。

## 4. 3.3V与USB供电分支

方案A：24→12V辅助；24→5.08V→USB/外部5V OR→SY8089A→3.3V；24→170V。保留现有USB仅逻辑供电行为较容易，但仍须核查3.3V瞬态/800mA预算与每级效率。新12V辅助必须承担三片HV5622、三片CD40109B、UC3843控制/栅极驱动和保护偏置负载，并按真实静态/时钟电流定额，不能凭“驱动不消耗灯管电流”忽略它。

方案B：24→12V辅助；24→3.3V；24→170V。减少逻辑供电一级；TPS54202在24→3.3V理想500kHz导通约275ns，26.4V/630kHz约198ns，高于手册110ns典型最小导通时间，仅支持初筛，不等于全角点保证。若仍需USB离线编程供电，需USB5→3.3V独立转换与3.3V电源OR/互斥控制，防止互灌；若USB仅数据，需要定义VBUS检测和3.3V缺失行为。不能将24V接USB OR点，也不能忽略USB插入/移除顺序。

12V辅助若采用24→12线性稳压，损耗为(24−12)×Iaux；例如50mA即0.6W，仅作量级示例，不是已核实负载。以降压开关作为研究优先路线，器件尚未冻结。
