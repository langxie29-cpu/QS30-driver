# G0 评审清单（架构与成本方向确认）

供用户在 G1 之前逐项确认；未确认项保持 OPEN。

## 1. 架构
- [ ] 采用三板架构：中央主板（含中心 3 管）+ 左右显示模块（左右同板）
- [ ] 驱动方案：3×HV5622PG-G（PQFP-44），不用 74HC595+MPSA42
- [ ] 数据链：96 bit 级联（MCU→L→C→R，含 L→C 回线），不做独立数据线
- [ ] 模块接口：QS30-DISPLAY-MODULE/REV.A（LV 16P IDC + 独立 HV 2P）

## 2. 电气修复确认
- [ ] U8 比较器改 1.0 V 基准（LM393 3.3 V 供电共模）
- [ ] DRV_PG = 11.2 V（迟滞 ~0.34 V）
- [ ] OVP 验收窗口 192.5–204.5 V（1% 电阻）或改用 0.1% 电阻收紧
- [ ] SAFETY_LOOP 模块在位检测纳入硬件关断路径

## 3. 成本与采购
- [ ] 接受 BOM-B 为推荐档；是否接受 BOM-C（备件 HV5622 + 0.1% 电阻）
- [ ] 授权开始询价：HV5622PG-G ×3(+1)、13 脚管座 ×9(+2)、4 块 PCB、LV/HV 连接器与线束
- [ ] 明确：辉光管 9 只为已有库存（历史 160 元），不计入本次现金支出

## 4. 机械与安全
- [ ] 确认三管安装方式：支架/面板（推荐）或 100×150 板档
- [ ] 确认 HV 连接器须 ≥300 V DC 额定、防触碰、Pin1 标识
- [ ] 确认安全等待时间（计算泄放 172→50 V ≈0.76 s；建议 ≥15 s 接触前等待）

## 5. 工具与验证
- [ ] 是否安装 KiCad/立创EDA 以产出原生工程与 ERC/DRC（H9-06）
- [ ] 是否准备高压台架（差分探头 ≥1 kV、隔离、假负载）用于 G3
- [ ] 是否允许先做 G2 低压样板（不接高压）

## 6. 结论
- 全部确认 → G0 通过，进入 G1（原理图/选型复核）
- 任一未确认 → 保持 G0，禁止打样
