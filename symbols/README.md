## 3. 建库步骤（立创EDA 专业版）

1. 新建符号 → 名称 `QS30-1`，位号前缀 `J_T`。
2. 画矩形外框（建议 20 × 30 mm 视觉比例，非机械尺寸）。
3. 放置 13 个引脚，按上表填 **脚号** 与 **名称**；引脚朝向：阳极在上、阴极在下或按可读性分列（不影响网表）。
4. 引脚电气类型：1/8 设为 `无连接/NC`；2 设为 `阳极`；其余设为 `无源/阴极`（立创EDA 中按可用的电气类型选择即可）。
5. 属性里填写：`Manufacturer=南昌电子管厂`、`MPN=QS30-1`、`Datasheet=S6 原厂说明书（归档文件）`、`Status=HOLD(批次验证)`。
6. 关联封装：使用 13 脚管座封装草案（H03 关闭后替换为实测版）；**封装焊盘号必须等于 1–13**。
7. 在符号上标注：`1/8脚悬空`、`Ea=170V Ra=20k Ik≈2.25mA`，避免后人误接。

## 4. 建库后必须做的核对（签审证据）

- [ ] 原理图符号脚号 = 本表 = 封装焊盘号 = 实物管脚号（4 方一致，逐页签字）
- [ ] 用"1 脚方向图 + 1:1 打印图"与实物管座比对
- [ ] 3D 模型只作外观参考，**不得**用外观吻合替代脚号正确
- [ ] 与 `docs/qs30_1_pin_mapping.csv` 逐行比对（可用脚本：`python design/build.py` 的 ERC 检查不覆盖本项，需人工签字）

## 5. 已知限制

- 符号电气映射 VERIFIED（原厂图）；**观察面/封装坐标**仍是 H03 的实测内容。
- 无小数点/冒号电极；若后续需要，必须另立显示器件与 BOM/HOLD，不占用 1/8 脚。
